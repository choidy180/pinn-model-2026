## 🚀 PINN: 실시간 공간 검색 기반 스마트 팩토리 스트리밍 플랫폼

PINN(PIM-based INjection Molding Navigator)은 사용자 친화적인 인터페이스를 통해 공장 내 **자재부터 최종 조립까지** 전체 제조 공정을 실시간으로 모니터링하고 관리할 수 있는 **공간 검색 기반 리얼 스트리밍 플랫폼**입니다. 공장 내부를 시각화하고, 각 설비 및 구역의 실시간 데이터를 영상 스트리밍과 통합하여 제공함으로써 **현장 상황을 직관적으로 파악**하고 **신속한 의사 결정**을 지원합니다.

-----

## 🌟 주요 컨셉 및 특징

### 1\. 공간 검색 기반 실시간 스트리밍 (Real-Time Spatial Monitoring)

  * **공간 구조화:** 공장의 물리적 레이아웃을 디지털 트윈 형태로 구성하여, 사용자가 **직접 영상을 보며** 원하는 위치나 설비 상태를 **지도처럼 검색**하고 접근할 수 있습니다.
  * **리얼 스트리밍:** 모든 설비 및 공정 구역의 **CCTV/센서 데이터**를 실시간으로 스트리밍하여 현장의 생생한 상황을 지연 없이 파악할 수 있습니다.

### 2\. 제조 공정별 통합 모니터링

자재 입고부터 출고까지의 **전체 사출성형 공정**을 단일 플랫폼에서 관리합니다.

  * **자재창고(Warehouse):** 원자재 입/출고 현황, **건조기** 작동 상태 및 재고 수준 실시간 확인.
  * **사출설비(Injection Facilities):** A, B, C, D 설비별 **실시간 운전 조건(온도, 압력 등)** 및 상태 이상 감지.
  * **건조실(Drying Room):** 온도 및 습도 현황, 건조 공정 진행 상황 모니터링.
  * **패킹(Packing):** 최종 제품의 포장 및 검수 과정 실시간 확인.
  * **조립라인(Assembly Line):** 각 공정 단계별 진행률 및 로봇/작업자의 동작 스트리밍.

## 🛠️ 주요 기능 모듈

| 모듈 | 상세 기능 | 설명 |
| :--- | :--- | :--- |
| **자재창고 관리** | 창고 현황, 건조기 상태 패널 | 원자재 재고 수량 및 이력 조회, 건조기 온도/습도 이상 여부 실시간 패널 제공. |
| **사출설비 현황** | 설비별 스트리밍, 설정 조건 조회 | 설비별 Live 영상 스트리밍과 함께, **형폐/형개 시간, 히터 온도, 형체력** 등 핵심 사출 조건을 조회하고 설정할 수 있습니다. |
| **건조실 모니터링** | 입구/현황/출구 뷰 | 건조실 전 공정의 온도, 습도, 이동 현황을 섹션별로 시각화하여 파악. |
| **패킹 & 조립라인** | 실시간 영상 스트리밍 | 포장 및 조립 라인의 작업 과정을 실시간 영상으로 확인하여 병목 현상 및 품질 이슈를 즉각적으로 감지. |
| **통합 검색 (Search)** | 조회, 클립 저장/공유 | 공정 이력, 설비 조건 변경 이력 등을 키워드로 **통합 조회**하며, 중요 영상 클립을 저장하고 공유할 수 있는 기능 제공. |

## ⚙️ 기술 스택 (예시)

이 프로젝트는 최신 웹 기술을 활용하여 빠르고 반응성이 뛰어난 인터페이스를 제공합니다.

  * **Frontend:** React (Next.js), TypeScript, styled-components
  * **Backend/API:** Node.js (또는 Python/Django, Spring Boot 등), RESTful API
  * **Real-time Streaming:** WebRTC, WebSocket (MPEG-DASH, HLS, RTMP 서버 연동 가능)
  * **Database:** PostgreSQL (시계열 데이터 관리를 위한 TimescaleDB 확장 고려)
  * **DevOps/Infra:** Docker, Kubernetes (배포 및 확장성 관리)

## 💡 시작하기 (Getting Started)

### Prerequisites

  * Node.js (v18+)
  * Yarn 또는 npm
  * (옵션) Docker

### Installation

```bash
# 1. 저장소 클론
git clone [Your Repository URL]
cd pinn-factory-streaming

# 2. 종속성 설치
npm install
# 또는
yarn install

# 3. 개발 서버 실행
npm run dev
# 또는
yarn dev
```
